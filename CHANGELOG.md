# Changelog

All notable changes to Inkumo are recorded here.

## Unreleased

- Added bottom-center page markers and a last-page-only copyright footer derived
  from `content/header.tex`.
- Reworked section and entry rows to support wrapping, pagination, and long
  date or role fields without overlap.
- Expanded the icon registry with bundled Devicon logo glyphs for programming
  languages, infrastructure, data systems, and developer tools.
- Added PDF validation, CI checks, and license/font notices for public use.

## 0.1.0 - 2026-05-05

- Introduced the Inkumo XeLaTeX resume class.
- Added modular content sections, platform icon registry, local font fetching,
  and GitHub Actions PDF build validation.
